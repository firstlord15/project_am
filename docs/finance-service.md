# Документация сервиса финансов
**Название модуля:** `finance-service`

**Зона ответственности:** Фиксация доходов и расходов, управление финансовыми категориями, предоставление данных для аналитических графиков.

### 1. Архитектура и Доменная модель

Сервис изолирован и имеет собственную базу данных (PostgreSQL). Основные бизнес-сущности:

- **Category:** Категории транзакций (Доходы/Расходы), привязанные к конкретному пользователю.
- **FinancialRecord:** Конкретная запись о финансовой операции. Хранит название, количество, единицу измерения, цену за единицу и итоговую сумму.

### 2. Технологический стек

- **Язык и фреймворк:** Java 17, Spring Boot 4
- **База данных:** PostgreSQL
- **Миграции БД:** Liquibase
- **Аутентификация:** Валидация JWT-токенов (выданных `auth-service`)

### 3. Зависимости и интеграции

Сервис не делает синхронных HTTP-запросов к другим модулям.
Авторизация работает через проверку подписи JWT-токена (общий секретный ключ, выдаваемый `auth-service`, берётся из Vault).
Идентификатор пользователя (`userId`) извлекается напрямую из токена.

### 4. API Эндпоинты

| Метод    | Путь                    | Описание                                    | Доступ      |
|----------|-------------------------|---------------------------------------------|-------------|
| **POST** | `/api/v1/categories`    | Создать новую категорию                     | Авторизован |
| **GET**  | `/api/v1/categories`    | Получить список категорий пользователя      | Авторизован |
| **POST** | `/api/v1/records`       | Добавить финансовую запись                  | Авторизован |
| **GET**  | `/api/v1/records/{id}`  | Получить запись по ID                       | Авторизован |
| **GET**  | `/api/v1/records/stats` | Получить агрегированные данные для графиков | Авторизован |

### 5. Конфигурация и запуск окружения

Для локального запуска сервиса требуются следующие переменные окружения:

* `DB_HOST` — адрес базы данных PostgreSQL
* `DB_PORT` — порт базы данных (по умолчанию 5432)
* `DB_USER` — пользователь БД
* `DB_PASSWORD` — пароль БД (хранится в Vault)
* `JWT_SECRET` — общий секретный ключ для валидации подписи токенов (тот же, что использует `auth-service` для подписи)

Команда для локального запуска через Docker:
`docker-compose up finance-service -d`
